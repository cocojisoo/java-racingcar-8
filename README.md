# java-racingcar-precourse

## 구현할 기능

### 자동자 경주 로직
[x] 사용자에게 받은 자동차 경주 횟수만큼 시행한다.
[x] 쉼표(,)로 자동차의 이름을 구분하여 추출한다.
[x] 0~9 사이의 무작위 값 중 무작위 값이 4 이상일 경우에 전진시킨다.
[x] 경주가 끝나면 우승자를 구분한다.


### 입력 및 출력
[x] 안내 메세지를 출력한다. ('경주할 자동차 이름을 입력해주세요(쉼표(,)로 구분, 5자 이하)')
[x] 사용자에게서 자동차 이름, 시도할 횟수를 입력 받는다.
[x] 차수별 실행 결과를 출력한다. 이때 전진 결과를 하이픈(-)으로 출력한다.
[x] 경주가 끝나면 우승자를 출력한다. 우승자가 여러명일 경우엔 쉼표(,)를 이용하여 구분한다.


### 예외처리
[x] 쉼표 뒤 이름이 들어가지 않았을 경우
[x] 이름이 5자를 넘긴 경우
[x] 시도가 0회로 입력된 경우
[x] 제어 문자를 사용했을 경우
[x] 제로 폭 문자를 사용했을 경우
[x] 양방향 제어문자를 사용했을 경우

## 고민한 점
문득 자동차 이름의 예외처리 기준을 어디까지로 정해야할까 고민이 들어서 생각해봤습니다. 보통 닉네임을 지을 때 영문 대소문자(A–Z, a–z), 숫자(0–9), 언어 문자(한글, 라틴 확장, 히라가나/가타카나 등)에 추가적으로 언더스코어(_), 하이픈(-), 점(.) 정도로 닉네임의 설정을 제한해두곤 하는데 어느 웹사이트에 가면 이모지, 여러 괴랄한 문자까지 허용되서 무슨 기준일까 하고 찾아보았습니다. 먼저 회원가입이 있는 서비스에서는 동형 의의어 + 스크립트 믹싱을 사용해서 사칭할 수 도 있다 하고 방향제어(BiDi) 문자들은 화면 표시순서랑 내부 저장순서가 다르기에 로그 추적이 안될 수 있고 0폭 문자같이 보이지 않는 문자를 사용해서 필터를 우회할 수 있다 등등 여러 문제점이 있다는 사실을 알게되었습니다. 문제가 되는 문자들이 많지만 이중에서 제일 크리티컬 해보이는 방향제어, 제로폭문자 예외처리를 구현해보았습니다 솔직히 이 예외처리들은 이번 과제에선 호들갑이긴 하지만 찾아본게 아까워서 넣어봤습니다!
